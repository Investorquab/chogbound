CHOGBOUND MOCKUPS
Six standalone responsive static HTML/CSS screens.

Open 01-landing.html first. Use the header links to move between mockups.
Each file embeds its own styles and original inline SVG Chog illustration.
No app logic, wallet connection, live data, or backend calls are included.
The Coach and Replay pages include empty, loading, and error state specimens.

Design notes:
- Display: Barlow Condensed 700/800/900 for punchy arena typography.
- Numbers: IBM Plex Mono for records, ranks, timers, and trait readouts.
- UI text: Inter for compact readable body copy.
- Palette follows the brief.
